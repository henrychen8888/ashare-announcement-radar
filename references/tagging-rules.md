# 打标规则与定级逻辑

改 `tagger.py` 之前必读。这里记录每条规则**为什么长这样**，以及不这么写会出什么错。

---

## 三级管线

```
columns + title  →  ① 主题归类  →  ② 方向打分  →  ③ 定级  →  direction / level / score
```

三件事分开算，互不覆盖。主题是「这是什么类型的事」，方向是「利好还是利空」，
等级是「重不重要」。混在一起算就会出现「回购 = 一定是利好 = 一定重大」这类错误。

---

## ① 主题归类

13 个主题，`TOPIC_RULES` 自上而下匹配，**先命中先归属**，顺序即优先级：

```
业绩 → 并购重组 → 增减持 → 回购 → 合同中标 → 融资 → 股权激励
→ 风险警示 → 诉讼担保 → 资金募集 → 经营投资 → 公司治理 → 其他
```

顺序不能随意调。例：「业绩预告」排在「并购重组」之前，否则
「关于收购XX的业绩承诺完成情况」会被归成并购重组，而它本质是业绩事项。

---

## ② 方向打分

两路来源，权重不同：

- **`columns[].column_name`（结构化，主依据）**：交易所披露时打的分类标签，准。
- **`title`（文本，兜底 + 修正）**：只在 column 缺失或不准时起作用。

合并规则（`score_direction()`）：

| 情形 | 取值 |
|---|---|
| 仅有 column | 直接取绝对值最大的 column 分值 |
| 仅有 title | 取绝对值最大的 title 分值 |
| 两者同号 | column 分值 **再加强一档**（±1） |
| 两者异号 | column 分值 **减半**（`//2`） |

设计意图：标题常用夸张措辞（「重磅」「重大突破」），不能让它主导方向；
但它和 column 冲突时说明有隐情（比如分类是「收购」但标题写「终止收购」），
此时削弱强度而非直接反转——真正的反转交给下一节的否定语义表。

---

## ③ 定级

### S 级：白名单制，不用分数

**这是本技能最重要的一条。** 分数叠加定级会导致强度虚高：

> 实测（2026-10-29，801 条）：初版 S 级 = 240 条，占比 30%。原因是
> 「回购预案 +2」与标题「回购 +2」同号再加一档到 +3，一堆正常回购被顶成「重大」。

改为**结构化白名单**后 S 级降到 87 条（10.9%），每一条都经得起看。

S 级的定义：**次日开盘前必须知道的事**。白名单只收硬信号：

| 方向 | 白名单（column 或标题命中） |
|---|---|
| 利好 | 重大合同、中标、控股股东增持、要约收购报告书、吸收合并、增发/首发获准、业绩预增、收购出售资产 |
| 利空 | 处罚、立案、监管工作函、实施退市风险警示、终止上市、业绩预减/预亏、股份冻结、停牌、控股股东减持 |

其余按分数兜底：`|score| ≥ 2` → A，`≥ 1` → B，否则 N。

### 文件型公告降级

`DOC_LIKE` 命中的公告（专项报告、核查意见、法律意见书、审计报告、最近五年、
承诺、补充公告、更正公告、摘要、议案、独立董事、监事会……）**方向保留，等级压到 B/N**。

理由：这类是再融资或重组的配套披露文件，不是新发生的事件。
不识别就会把「最近五年被处罚情况」当成新增处罚，把「法律意见书」当成利好。

---

## 否定语义（优先级最高）

标题字面命中关键词但语义相反，会把方向整个判反。`NEGATIVE_OF_BEARISH` 在打分之后覆盖：

| 标题特征 | 覆盖为 | 原因 |
|---|---|---|
| 终止减持 / 提前终止减持 / 减持计划终止 | **+2** | 不减持了，是利好 |
| 未减持 / 不减持 / 零减持 / 未实施减持 / 放弃减持 | **+1** | 同上，弱一些 |
| 终止回购 / 回购方案终止 / 不再回购 | -1 | 护盘预期落空 |
| 终止收购 / 收购终止 / 重组终止 | -2 | 外延预期破灭 |
| 撤回发行 / 终止发行 / 中止审查 / 终止审查 | -1 | 融资受阻 |

**实测事故（2026-10-29）：** `603600` 的「关于公司董事、高级管理人员**未减持**公司股份
并提前**终止减持**股份计划的公告」，初版按「减持」打成 S 级利空。这条方向完全反了。

**绝对不要写裸「终止」。** 它会把「终止上市」这种最重的利空打成中性。
必须写成「终止减持 / 终止回购 / 终止收购」这类带宾语的组合。

## 涨停判定

```python
# 交易所涨停价直接比对（腾讯行情 idx 47 / 48），容差 0.015 元
|涨停价 - 现价| < 0.015  → 涨停
```

**不用「涨幅 ≈ 10%」判涨停**，原因有三：

1. **涨停幅度分档**：主板 10%、创业板/科创板 20%、北交所 30%、ST 5%。
   用统一阈值必然错判一批。
2. **浮点取整**：`600715` 昨收 1.96、涨停价 2.16，实际涨幅 **+10.19%**。
   低价股按百分比阈值会漏判。
3. **新股不设涨跌幅**：实测 `920306` 上市首日 +120.54%，这是真实数据，
   自检的越界阈值因此设成 ±900 而不是 ±100。

**交叉验证（可复用）：** 涨停股按交易所规则须披露「股票交易异常波动公告」。
实测 10-29 判出 12 只涨停股，其中 10 只当日确实发了异动公告 —— 数据自洽。
这个校验比单元测试更能证明判定链没跑偏，改判定逻辑后建议重跑一次。

## 噪音标记

`is_noise = (方向为中性) and (主题 ∈ {资金募集, 公司治理})`。
看板默认隐藏这类，数量大、短线价值低。注意限定条件是「中性」：
公司治理主题里若出现控股股东变更，方向非中性，不会被当噪音吞掉。

## 改规则的流程

1. 先跑 `python tagger.py` —— 文件底部有 8 条内置用例，能快速看分布。
2. 加否定语义用例，至少覆盖：正常减持、未减持、终止减持、终止上市、终止回购。
3. 用真实数据回归：

```bash
export AB_HOME=<你的数据目录>
python <skill_dir>/scripts/fetch.py --no-content      # 重新打标
python -c "
import json; d=json.load(open('$AB_HOME/data/<日期>.json',encoding='utf-8'))
s=d['stats']; print('S/A/B/N =', s['S'],s['A'],s['B'],s['N'])
print('S 级占比 %.1f%%' % (100*s['S']/s['total']))"
```

4. 判据：**S 级占比应落在 8%~15%**。明显高于此说明白名单太宽或分数又参与了定级；
   低于 5% 说明漏了真信号。

## 已知局限（不要当成 bug 修）

- **依赖 column 质量。** 东财偶尔给 `column_name` 是「其它」，此时完全靠标题关键词，
  准确率会下降。无法根治，只能靠否定语义表兜住方向反转。
- **主题≠行业。** 本技能不输出行业归属。东财公告接口不带行业字段，
  要行业需另接数据源，不要从主题名推测。
- **公告时间与行情时间不同源。** 行情是抓取时刻的快照，盘后抓取即收盘价；
  盘中抓取则是实时价。看板脚注已标注生成时间，解读时需注意。
- **不做收益预测。** 「S 级 + 涨停」只说明事件重大且有资金反应，
  不等于次日会涨。任何方向性结论都不在技能范围内。
